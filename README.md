# 🎓 Student Placement Analytics & Machine Learning Prediction

An end-to-end data analytics and machine learning solution designed to analyze student academic and technical parameters, understand factors influencing campus placements, and predict placement outcomes.

---

## 📌 Project Overview
This project combines **Exploratory Data Analysis (EDA)**, **Supervised Machine Learning**, and **Power BI Interactive Dashboards** to deliver actionable insights into student employability.

* **Dataset Size:** 1,000 Student Records
* **Overall Placement Rate:** 60.80%
* **ML Model Accuracy:** 91.50% (Tested on 200 hold-out samples)

---

## 🛠️ Tech Stack & Tools
* **Programming & ML:** Python (`pandas`, `numpy`, `scikit-learn`)
* **Business Intelligence:** Power BI (DAX, Interactive Dashboards, Data Modeling)
* **Environment:**  VS Code

---

## 📊 Dashboard Architecture (Power BI)

### **Page 1: Student Placement Analytics**
* **KPI Metrics:** Total Students (1,000), Average CGPA (7.74), Overall Placement Rate (60.80%).
* **Academic Correlation:** Placement rate distribution across CGPA categories (demonstrating the drop from 9–10 CGPA down to <6 CGPA).
* **Department Performance:** Comparative breakdown across CS, Data Science, IT, and Electronics.
* **Skill Analysis:** Evaluation of Java, Python, and DSA proficiency levels between placed and unplaced candidates.

### **Page 2: Machine Learning Prediction & Evaluation**
* **Model Accuracy:** 91.50% on test predictions.
* **Confusion Matrix / Breakdown:** Actual vs. Predicted Placement distribution (183 Correct vs. 17 Incorrect).
* **Prediction Confidence:** Probability score brackets showing high-confidence classification in the 80–100% tier.

---

## 🧠 Key Findings & Insights
1. **Academic Performance Matters Most:** A direct, steep correlation exists between CGPA and placement success. Students scoring >8.0 CGPA have over an 80% placement rate.
2. **Technical Mastery:** Placed students consistently exhibit higher average skill ratings in Data Structures & Algorithms (DSA), Java, and Python.
3. **High ML Reliability:** The trained model reliably isolates borderline profiles and achieves strong predictive fidelity with minimal false positives.
